# تطبيق طلبات تاج الملكة

تطبيق Android Native يعرض لوحة الطلبات:

`https://tajalmalka.com/admin/products/list/vendor?status=1`

## المميزات

- فتح لوحة الإدارة داخل تطبيق أندرويد مع JavaScript وDOM Storage.
- الاحتفاظ بكوكيز جلسة تسجيل الدخول داخل WebView.
- سحب الشاشة لأسفل لتحديث الصفحة.
- مراقبة تغيّر قائمة الطلبات داخل الصفحة.
- خدمة أمامية تفحص صفحة الطلبات كل 30 ثانية أثناء تفعيل المراقبة.
- إشعار قوي بصوت Alarm واهتزاز عند رصد طلب جديد/تغيير في قائمة الطلبات.
- إعادة تشغيل المراقبة بعد إعادة تشغيل الهاتف إذا كانت مفعّلة مسبقًا.
- GitHub Actions يبني APK تلقائيًا عند كل Push على فرع `main`.

## أول تشغيل

1. ثبّت الـ APK.
2. افتح التطبيق وسجّل الدخول إلى لوحة تاج الملكة.
3. وافق على إذن الإشعارات.
4. اترك إشعار «مراقبة الطلبات الجديدة مفعّلة» ظاهرًا؛ هذا يعني أن المراقبة تعمل.

## ملاحظة تقنية مهمة

التطبيق الحالي يستطيع التنبيه أثناء فتح التطبيق، ويستخدم خدمة أمامية للمراقبة في الخلفية. أفضل حل للتنبيه الفوري 100% مع استهلاك بطارية أقل هو أن يوفّر خادم الموقع API/Webhook عند إنشاء الطلب، ثم نربطه بـ Firebase Cloud Messaging (FCM). بدون API من الموقع، المراقبة تتم عن طريق فحص صفحة الطلبات دوريًا.
